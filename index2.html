درباره من

خلاصه‌ای از حوزه کاری و ابزارهایی که باهاشون کار می‌کنم.

تمرکزم روی توسعه اندرویده: ساخت اپ با Kotlin و Java، کار روزمره با Android Studio و کنترل نسخه با Git و ابزارهایش. در کنارش بک‌اند و ابزارهای تحت وب را با PHP می‌سازم و با HTML و CSS آشنام. APIها را با Postman و ابزارهای مشابه تست می‌کنم، طراحی رابط کاربری را با Adobe XD انجام می‌دم و روی ویندوز و لینوکس راحتم. به کد تمیز و قابل تست اهمیت می‌دم و همیشه دنبال یادگیری ابزارهای جدیدم.

گروه ابزارها
سیستم‌عامل Windows، Linux
زبان‌ها Kotlin، Java، Android، PHP، HTML، CSS
ابزار کدنویسی Android Studio، PhpStorm، VS Code
گیت Git، GitHub، GitHub Desktop، GitKraken، SmartGit، GitForce، Sourcetree، TortoiseGit، Fork، Tower
تست API Postman، Bruno، Yaak، HTTPie
دیزاین Adobe XD
